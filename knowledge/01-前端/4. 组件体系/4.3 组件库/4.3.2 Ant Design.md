## 库概况

Ant Design 是 React 里最成熟的企业级设计体系之一，由蚂蚁集团体验技术团队推动。官方文档不仅有组件库，还有设计原则、实践案例和资源体系，核心价值是把设计语言、研发规范和页面模板一起打通。

它的设计价值观是“自然、确定性、意义感、生长性”，这让它特别适合复杂中后台和组织级产品。官方案例页里能看到蚂蚁金融科技、OceanBase Cloud Platform、语雀、Ant Design Pro、阿里云流计算等实践。

Ant Design 的优势不只是组件多，而是它把设计语言、组件 API、页面模板和工程实践连在一起了。很多团队选择它，是因为它提供的不只是按钮和表格，而是一套更容易统一团队认知的工作方式。

它特别适合组织级产品、控制台、SaaS、运营系统和内部平台。只要你的页面里有大量表单、列表、筛选、流程和权限控制，Ant Design 往往能提供很成熟的默认解法。

## 组件清单

#### 基础与布局

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Button | 发起主要/次要/危险操作 | `type`、`danger`、`ghost` |
| Typography | 标题、正文、说明文字 | `Title`、`Text`、`Paragraph` |
| Space | 元素间距控制 | `size`、`direction` |
| Flex | 快速对齐布局 | `justify`、`align` |
| Grid | 栅格布局 | `Row`、`Col` |
| Divider | 分隔内容区块 | `type`、`orientation` |

```tsx
import { Button, Flex, Typography } from "antd";

export default function Toolbar() {
  return (
    <Flex justify="space-between" align="center">
      <Typography.Title level={4}>用户管理</Typography.Title>
      <Button type="primary">新建用户</Button>
    </Flex>
  );
}
```

#### 数据录入

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Form | 字段收集、校验、布局 | `layout`、`Form.Item` |
| Input | 单行输入 | `placeholder`、`allowClear` |
| Select | 下拉选择 | `options`、`mode` |
| DatePicker | 日期时间选择 | `picker`、`showTime` |
| Checkbox | 勾选项 | `Checkbox.Group` |
| Radio | 单选项 | `Radio.Group` |
| Switch | 开关 | `checked`、`onChange` |
| Upload | 文件选择与上传 | `beforeUpload`、`listType` |
| Cascader | 层级选择 | `options`、`changeOnSelect` |
| TreeSelect | 树状选择 | `treeData`、`multiple` |

```tsx
import { Button, Form, Input, Select } from "antd";

export default function UserForm() {
  return (
    <Form layout="vertical">
      <Form.Item label="用户名" name="username" rules={[{ required: true }]}>
        <Input placeholder="请输入用户名" />
      </Form.Item>
      <Form.Item label="角色" name="role">
        <Select options={[{ label: "管理员", value: "admin" }]} />
      </Form.Item>
      <Button type="primary" htmlType="submit">保存</Button>
    </Form>
  );
}
```

#### 数据展示

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Table | 表格列表 | `columns`、`dataSource` |
| Descriptions | 详情信息 | `items`、`column` |
| List | 列表展示 | `renderItem` |
| Card | 内容卡片 | `title`、`extra` |
| Tag | 状态标签 | `color`、`icon` |
| Badge | 数量/状态提醒 | `count`、`status` |
| Statistic | 指标卡片 | `value`、`prefix` |
| Timeline | 时间线 | `Timeline.Item` |
| Empty | 空数据 | `description` |

```tsx
import { Table, Tag } from "antd";

const columns = [
  { title: "姓名", dataIndex: "name" },
  {
    title: "状态",
    dataIndex: "status",
    render: (status: string) => <Tag color="green">{status}</Tag>,
  },
];

export default function UserTable({ data }: { data: object[] }) {
  return <Table rowKey="id" columns={columns} dataSource={data} />;
}
```

#### 导航与反馈

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Menu | 侧边或顶部导航 | `items`、`selectedKeys` |
| Tabs | 内容切换 | `items`、`activeKey` |
| Breadcrumb | 路径导航 | `items` |
| Steps | 流程步骤 | `current`、`items` |
| Pagination | 分页 | `current`、`pageSize` |
| Dropdown | 下拉菜单 | `menu`、`trigger` |
| Modal | 对话框 | `Modal.confirm()`、`open` |
| Drawer | 抽屉 | `open`、`onClose` |
| Message | 全局消息 | `message.success()` |
| Notification | 通知 | `notification.open()` |
| Alert | 内联提示 | `type`、`message` |
| Popconfirm | 二次确认 | `title` |
| Tooltip | 悬浮提示 | `title`、`placement` |

```tsx
import { Modal, message } from "antd";

function removeUser() {
  Modal.confirm({
    title: "确认删除用户？",
    onOk: async () => {
      await deleteUser();
      message.success("删除成功");
  },
});
}
```

Ant Design 里最常见的一批组件通常包括：

```text
基础：Button / Typography / Space / Flex / Grid
录入：Form / Input / Select / DatePicker / Upload
展示：Table / Card / Descriptions / Tag / Badge
导航反馈：Menu / Tabs / Pagination / Modal / Drawer / Message
```

其中最值得先掌握的是 `Form`、`Table`、`Modal`、`Menu`、`Pagination` 和 `ConfigProvider`，因为它们最能体现 Ant Design 的企业级思路。

## 适用与使用

Ant Design 适合 React 企业应用、管理后台、SaaS、流程配置平台、数据密集页面。它也很适合作为组织级统一方案，因为页面模板、设计资源和组件生态比较完整。

推荐的使用方式是先接受其默认设计语言，再逐步通过 `ConfigProvider`、主题 token 和业务封装做统一：

```tsx
<ConfigProvider
  theme={{ token: { colorPrimary: "#0f766e", borderRadius: 6 } }}
>
  <App />
</ConfigProvider>
```

如果项目已经采用 ProComponents、Ant Design Pro 这类页面模板，选型收益会更高。若项目追求极轻量、极自由视觉或纯移动端体验，Ant Design 就不一定是最优解。

使用 Ant Design 时，建议先接受它的规范，再做有限定制。尤其是表单布局、信息密度、按钮层级和表格结构，先顺着体系走，后面才容易统一业务封装。

如果项目后续可能扩展为多端或强品牌视觉，Ant Design 仍然能用，但你要提前评估主题改造成本。它更像“成熟企业级底盘”，不是那种拿来就可以随意改成极个性风格的库。
