## 库概况

Arco Design 是面向企业级产品的设计系统与组件库，覆盖 React 和 Vue 生态。它和 Ant Design 类似，不只是组件集合，也包含设计规范、主题能力和工程资源，适合组织内多项目、多技术栈共享设计语言。

它的优势是企业后台场景完整、视觉较现代、React/Vue 双生态覆盖较好。对于既有 React 又有 Vue 项目的团队，Arco 的价值不只是复用组件，还包括统一状态、交互和主题表达。

Arco 更适合“组织希望统一设计语言，但技术栈不完全统一”的场景。比如一个团队里既有 React 控制台，也有 Vue 管理端，如果希望按钮、表单、空态、弹窗和主题表达尽量一致，Arco 的双生态覆盖就很有价值。

它的视觉相对现代，信息密度和中后台场景也比较平衡。和 Ant Design 相比，Arco 的差异不只是风格，也包括团队生态、模板资源、主题工具和组织已有经验。

## 组件清单

#### 基础与布局

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Button | 操作入口 | `type` |
| Typography | 文本排版 | 标题、正文、说明 |
| Grid | 栅格布局 | `Row`、`Col` |
| Space | 间距控制 | `size` |
| Divider | 分隔线 | `orientation` |
| Layout | 页面骨架 | `Sider`、`Content` |

```tsx
import { Button, Space, Typography } from "@arco-design/web-react";

export default function Header() {
  return (
    <Space>
      <Typography.Title heading={5}>用户管理</Typography.Title>
      <Button type="primary">新建</Button>
    </Space>
  );
}
```

#### 表单输入

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Form | 表单容器 | `layout`、`rules` |
| Input | 文本输入 | `placeholder` |
| Select | 下拉选择 | `options` |
| DatePicker | 日期选择 | `showTime` |
| Checkbox | 勾选 | `checked` |
| Radio | 单选 | `Radio.Group` |
| Switch | 开关 | `checked` |
| Upload | 文件上传 | `action` |
| Cascader | 级联选择 | `options` |
| TreeSelect | 树形选择 | `treeData` |

```tsx
import { Button, Form, Input, Select } from "@arco-design/web-react";

export default function UserForm() {
  return (
    <Form layout="vertical">
      <Form.Item label="昵称" field="nickname" rules={[{ required: true }]}>
        <Input placeholder="请输入昵称" />
      </Form.Item>
      <Form.Item label="角色" field="role">
        <Select options={[{ label: "管理员", value: "admin" }]} />
      </Form.Item>
      <Button type="primary" htmlType="submit">保存</Button>
    </Form>
  );
}
```

#### 数据展示

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Table | 列表数据 | `columns`、`data` |
| List | 列表 | `render` |
| Tree | 树形结构 | `data` |
| Tag | 状态标签 | `color` |
| Descriptions | 详情展示 | `column` |
| Card | 卡片容器 | 默认插槽 |
| Avatar | 头像 | `shape` |
| Statistic | 指标展示 | `value` |
| Empty | 空状态 | `description` |

```tsx
import { Table, Tag } from "@arco-design/web-react";

const columns = [
  { title: "姓名", dataIndex: "name" },
  { title: "状态", dataIndex: "status", render: () => <Tag color="green">启用</Tag> },
];

export default function UserTable({ data }: { data: object[] }) {
  return <Table columns={columns} data={data} />;
}
```

#### 导航与反馈

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| Menu | 导航菜单 | `selectedKeys` |
| Tabs | 内容切换 | `activeKey` |
| Breadcrumb | 路径导航 | `items` |
| Steps | 步骤流程 | `current` |
| Pagination | 分页 | `total` |
| Dropdown | 下拉菜单 | `trigger` |
| Modal | 对话框 | `visible` / `open` |
| Drawer | 抽屉 | `visible` / `open` |
| Message | 消息提示 | `success()` |
| Notification | 通知提示 | `notice()` |
| Popconfirm | 二次确认 | `title` |
| Tooltip | 提示 | `content` |
| Spin | 加载 | `loading` |

```tsx
import { Message, Modal } from "@arco-design/web-react";

Modal.confirm({
  title: "确认删除？",
  onOk: () => Message.success("删除成功"),
});
```

Arco 的核心组件可以按中后台页面路径理解：

```text
页面结构：Layout / Grid / Space / Typography
信息录入：Form / Input / Select / DatePicker / Upload
信息展示：Table / Descriptions / Tag / Card / Statistic
流程反馈：Modal / Drawer / Message / Notification / Popconfirm
导航组织：Menu / Tabs / Breadcrumb / Steps / Pagination
```

其中 `Form`、`Table`、`Modal`、`Message`、`Layout` 是后台系统最常触达的组件。先把这些组件的默认行为、校验、弹层和主题覆盖吃透，再扩展到更复杂的业务封装会更稳。

## 适用与使用

Arco Design 适合中后台系统、企业级产品、跨 React/Vue 技术栈的组织，以及希望建立统一设计语言的团队。如果项目只是单一 Vue 后台，并且团队已经深度使用 Element Plus，切换收益未必足够明显。

使用时建议先统一主题和设计令牌，再按业务沉淀二次组件：

```text
Arco Design
  -> 统一主题配置
  -> 业务基础组件
  -> 页面模板
```

如果选择 Arco，不要只把它当作组件替换工具，而应该一起建立状态规范、空态规范、表单规范和发布规范。这样才能发挥设计系统的优势。

Arco 适合需要统一风格的企业平台、内部工具、B 端 SaaS 和多项目设计体系。它不一定适合追求极轻量、极少依赖或完全自定义视觉的项目。

落地时建议先选一个真实页面做样板，例如“筛选表单 + 表格 + 批量操作 + 弹窗编辑 + 空态错误态”。这个页面能暴露大部分组件库选型问题：表格是否顺手、表单校验是否符合团队习惯、弹窗交互是否稳定、主题是否容易覆盖。

```text
样板验证：
1. 表单字段和校验
2. 表格列渲染和分页
3. 弹窗编辑和二次确认
4. 空态、加载、错误态
5. 主题和国际化
```

如果样板页通过，说明 Arco 的默认能力和团队使用方式基本匹配；如果样板页大量依赖深层覆盖，就要谨慎评估长期维护成本。
