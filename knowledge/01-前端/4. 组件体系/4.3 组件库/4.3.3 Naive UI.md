## 库概况

Naive UI 是由 TuSimple 开源的 Vue 3 组件库，强调现代 API、TypeScript 友好和相对轻盈的视觉风格。它在 Vue 3 社区里很受欢迎，尤其适合不想完全套用传统 Element 风格的新项目。

它的优势是主题能力、类型体验和整体一致性都比较好，文档也偏向实用。对新 Vue 项目来说，它不是“最重”的企业后台库，但足够完整，能覆盖多数日常页面。

Naive UI 的气质更偏现代、简洁、轻灵活。它的组件命名、主题覆盖和 TypeScript 体验对 Vue 3 团队很友好，尤其适合不想一开始就套进传统中后台视觉范式的新项目。

它在“现代感”和“可定制性”之间做得比较平衡，适合中后台、内部系统、工具类产品和需要较强主题定制的业务场景。

## 组件清单

#### 基础与布局

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| NButton | 操作入口 | `type`、`ghost` |
| NSpace | 一维间距控制 | `justify`、`align` |
| NGrid | 栅格布局 | `cols`、`x-gap` |
| NLayout | 页面布局 | `position`、`has-sider` |
| NCard | 内容容器 | `title`、默认插槽 |
| NIcon | 图标渲染 | 配合图标组件使用 |
| NText | 文本展示 | `depth`、`type` |

```vue
<template>
  <n-space>
    <n-button>默认</n-button>
    <n-button type="primary">保存</n-button>
    <n-button type="error" ghost>删除</n-button>
  </n-space>
</template>
```

#### 表单输入

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| NForm | 表单容器与校验 | `model`、`rules` |
| NInput | 单行输入 | `v-model:value` |
| NSelect | 下拉选择 | `options`、`multiple` |
| NDatePicker | 日期时间选择 | `type` |
| NCheckbox | 多选 | `value`、`label` |
| NRadio | 单选 | `value` |
| NSwitch | 开关 | `v-model:value` |
| NUpload | 文件上传 | `action`、`default-file-list` |
| NInputNumber | 数字输入 | `min`、`max` |

```vue
<template>
  <n-form :model="form" label-placement="left">
    <n-form-item label="关键词" path="keyword">
      <n-input v-model:value="form.keyword" placeholder="请输入关键词" />
    </n-form-item>
    <n-form-item label="状态" path="status">
      <n-select v-model:value="form.status" :options="statusOptions" />
    </n-form-item>
  </n-form>
</template>

<script setup lang="ts">
import { reactive } from "vue";

const form = reactive({ keyword: "", status: null });
const statusOptions = [{ label: "启用", value: "enabled" }];
</script>
```

#### 数据展示

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| NDataTable | 表格数据 | `columns`、`data` |
| NDescriptions | 详情信息 | `label-placement` |
| NTag | 状态标签 | `type` |
| NTree | 树形结构 | `data`、`block-line` |
| NList | 列表 | `data`、`render` |
| NEmpty | 空状态 | `description` |
| NSkeleton | 占位加载 | `text`、`repeat` |

```vue
<template>
  <n-data-table :columns="columns" :data="data" />
</template>

<script setup lang="ts">
const columns = [
  { title: "姓名", key: "name" },
  { title: "角色", key: "role" },
];

const data = [{ name: "Alice", role: "管理员" }];
</script>
```

#### 导航与反馈

| 组件 | 作用 | 基础用法 |
| --- | --- | --- |
| NMenu | 导航菜单 | `options`、`value` |
| NTabs | 内容切换 | `value`、`tabsPlacement` |
| NBreadcrumb | 路径导航 | `items` |
| NPagination | 分页 | `page`、`page-size` |
| NDropdown | 下拉菜单 | `trigger`、`options` |
| NModal | 模态对话框 | `show`、`onUpdate:show` |
| NDrawer | 抽屉 | `show`、`placement` |
| NMessageProvider | 消息容器 | 配合 `useMessage` 使用 |
| NNotificationProvider | 通知容器 | 配合 `useNotification` 使用 |
| NPopover | 悬浮层 | `trigger`、`placement` |
| NTooltip | 提示 | `trigger` |

```vue
<template>
  <n-message-provider>
    <AppContent />
  </n-message-provider>
</template>
```

Naive UI 常见的核心组件可以先从这些开始：

```text
基础：NButton / NSpace / NGrid / NCard / NIcon / NText
录入：NForm / NInput / NSelect / NDatePicker / NUpload / NSwitch
展示：NDataTable / NDescriptions / NTag / NTree / NList / NEmpty
反馈：NModal / NDrawer / NMessageProvider / NNotificationProvider / NPopover / NTooltip
```

如果项目比较看重主题覆盖和组件一致性，Naive UI 的起点体验通常会比很多老牌库更舒服。

## 适用与使用

Naive UI 适合 Vue 3 新项目、内部平台、需要较强主题定制能力的业务系统。它特别适合团队想要比 Element Plus 更现代一点，但又不想走完全自研路线的情况。

实际使用时建议优先统一 `n-config-provider` 的主题覆盖，再逐步沉淀业务封装：

```vue
<n-config-provider :theme-overrides="themeOverrides">
  <App />
</n-config-provider>
```

如果项目已经有大量 Element 语义页面，迁移前最好先验证表单、弹窗、表格三类核心页面是否顺手。Naive UI 更适合新项目或风格升级，而不是无成本替换。

Naive UI 适合从零起步的 Vue 3 项目，也适合正在重建 UI 体系的项目。它的风险不在“不能用”，而在于如果团队已经有深度定制的 Element 体系，迁移会涉及大量语义和视觉重写。

如果你希望组件库在默认视觉上更现代一些，同时保留较强的主题能力，Naive UI 往往是很值得认真评估的选择。
